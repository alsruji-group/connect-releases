# Alsruji Connect — التحميلات

تطبيقات **Alsruji Connect** الرسمية لموظفي مجموعة السروجي. الروابط أدناه ثابتة وتشير دائماً إلى آخر إصدار.

| المنصة | التحميل | ملاحظات التثبيت |
|---|---|---|
| Windows (x64) | [Alsruji-Connect-Windows.exe](https://github.com/alsruji-group/connect-releases/releases/download/desktop-latest/Alsruji-Connect-Windows.exe) | عند أول تشغيل قد يظهر تحذير SmartScreen → «مزيد من المعلومات» → «تشغيل على أي حال» |
| macOS (Intel + Apple Silicon) | [Alsruji-Connect-macOS.dmg](https://github.com/alsruji-group/connect-releases/releases/download/desktop-latest/Alsruji-Connect-macOS.dmg) | اسحب التطبيق إلى Applications ثم افتحه أول مرة بالنقر الأيمن → «فتح» |
| Android | [Alsruji-Connect-Android.apk](https://github.com/alsruji-group/connect-releases/releases/download/mobile-latest/Alsruji-Connect-Android.apk) | فعّل «تثبيت من مصادر غير معروفة» ثم ثبّت فوق النسخة السابقة دون حذفها |

رقم الإصدار يظهر داخل التطبيق (سطح المكتب: «حول» · الموبايل: أسفل الإعدادات). سجل الإصدارات كاملاً في [Releases](https://github.com/alsruji-group/connect-releases/releases).

للدعم الداخلي: من داخل التطبيق → الإعدادات → «تحدث إلينا».
